# 生信绘图

将已有分析结果转化为可解释、可追溯、可重绘的图形。默认用中文沟通，保留基因与样本 ID 原文。绘图部分独立于分析脚本，不要求安装其他 skill 才能工作。

## 确认图要表达的问题

先读取用户指定的数据、现有绘图脚本和方法说明。确定图要回答的问题、目标读者、使用场景及分析单位。已有合适脚本时优先修改，保留用户确认的结果范围。

沿用项目的 R 或 Python 后端和既有风格；新项目根据输入对象、已有环境及用户偏好选择并记录。只有选择会显著影响交付时才询问，不为绘图安装整套分析环境。

优先执行用户明确的图形要求。没有指定图型时，根据比较、分布、关联、集合关系或层次结构选择表达方式，不自动生成与问题无关的图形全集。

## 检查与分析部分的交接

读取列名、代表记录、维度、样本信息及分析说明，确认：

- 样本、特征和分组 ID 可正确关联，连接不会无意扩大行数或丢失数据。
- 数值含义、单位、变换及归一化状态已知，缺失值未被默认为零。
- 比较方向、样本量和独立重复单位清楚，统计标注有对应结果来源。
- 已记录绘图对象的筛选、排序或背景定义，以及数据的生成脚本或运行标识。

缺失关键统计信息时先完成可独立进行的图形工作，并指出缺口；不要从截图猜测精确数值或自行补算显著性。只有图片参考时可借鉴样式，科学数据仍须来自用户数据或可核实来源。

改变模型、分析样本、统计过滤条件、差异检验或富集计算时返回分析任务。环境中有 bioinformatics-analysis 时可按需调用；只调整绘图样式时不要重跑分析。

## 图形与统计表达

绘图可执行有记录的显示层操作，如排序、为布局整理表格、分面或按预定规则生成显示矩阵。涉及重新估计模型或检验结果的步骤应作为分析步骤保存，不能隐藏在绘图脚本中。

- 热图：记录显示矩阵的变换、标准化方向、选取范围和聚类设置；标准化值与原始丰度含义分开标注。
- 差异结果图：核对效应方向、P 值类型和阈值；对零值或不可显示值的处理需记录，保留原始数据。
- 分布及分组图：区分独立样本、技术重复和配对观测，注明误差线含义；必要时显示个体观测与配对结构。
- 富集图：使用已计算的富集结果，注明显示指标、集合大小及筛选规则；不能把不同定义的指标混作同一尺度。
- 树图与比较图：核对树端点、分支量纲、物种或特征映射；不能因排版改变树的含义。

数值轴、图例和颜色应与数据一致。使用可区分的配色，必要时增加形状或线型，避免只依赖颜色。显示截断、对数坐标、遗漏值及筛选条件不得掩盖影响结论的信息。

## 可重绘实现

将数据路径、输出路径、分组顺序、标签、配色、画布尺寸和导出格式集中配置，避免写死个人路径。保留稳定的样本与特征 ID，显示名称另行映射。

区分探索图与正式图。正式多面板图保持字体、线宽、图例、面板编号和相同变量的配色一致；尺寸与格式按用户或目标期刊要求配置，未指定时记录采用的默认值。

每幅正式图同时保存源数据或其明确引用、绘图脚本、配置、图注和输出文件。源数据应足以重建图形，必要的筛选或显示变换保留代码。不把图片本身作为唯一结果。

## 验证与交付

执行脚本并检查日志、输出和显示数据之间的一致性。核对组别顺序、标签、样本数、图例、坐标、统计标注以及实际纳入图形的数据范围。

渲染并查看最终文件，检查裁切、文字重叠、缺字、颜色、图例遮挡和多面板对齐。不能仅根据文件存在宣称视觉检查通过；无法渲染的格式需说明未验证项目。

按需求交付预览图、适用的矢量或位图文件、源数据、脚本和图注。报告实际检查过的格式及尚未解决的限制。图片美化不应改变分析结论或静默排除不符合预期的数据。


## 图形配置与验收细则

为每张图明确图号或名称、要回答的问题、输入结果及来源、显示变量、比较对象、显示筛选与变换、面板结构、样式和导出要求。将这些内容放在项目已有配置或简明图形说明中；不为简单单图强制引入复杂配置框架。

按组别名称映射颜色和显示顺序，不能依赖数据当前行顺序；相同变量跨图保持相同映射。数据读入顺序改变不应悄悄改变组色或图例语义。随机布局记录种子，固定标签选择规则，避免凭视觉偏好反复挑选结果。

PCA 等降维的拟合、载荷和解释方差属于分析产物；绘图读取对应坐标与说明。若缺少这些产物，将计算作为显式分析步骤完成后再绘图。热图的显示标准化或聚类可以属于绘图步骤，但应输出其规则、显示矩阵和排序，不能用它覆盖原始分析矩阵。

将数据校验与视觉校验分别记录。数据检查比较图中实际样本、特征和分组与输入及筛选规则，标注过滤掉的记录数与原因。没有显著结果、仅剩一个分组或某面板无数据时，交付有解释的空结果或适用图形，不强行生成误导性图表。

视觉检查以实际导出的成品为准，在目标尺寸检查文字可读性；多格式导出分别检查适用的字体、页面尺寸、透明度和裁切。位图分辨率与物理尺寸一起记录，矢量格式不等于所有图层都是矢量。仅声明实际验证过的输出，不笼统承诺满足所有期刊要求。
