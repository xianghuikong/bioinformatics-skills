# Bioinformatics Skills

分为两个独立部分：**分析脚本**与**绘图**。既可以分别调用，也可以按“分析结果 → 绘图”的顺序协作。

| 部分 | Skill | 负责的工作 | 主要交付 |
| --- | --- | --- | --- |
| 分析脚本 | `bioinformatics-analysis` | 编写、执行、审查和修复数据处理与统计分析脚本，验证结果 | 脚本、配置、结果表、方法记录与绘图数据 |
| 绘图 | `bioinformatics-plotting` | 读取已有结果，编写和运行绘图脚本，统一样式、排版与导出 | 图形、绘图脚本、配置、源数据与图注 |

## 使用示例

分析脚本：

```text
使用 $bioinformatics-analysis 检查我的表达矩阵和样本表，
编写适合实验设计的分析脚本，验证输出，并整理交给绘图的结果与数据说明。
```

绘图：

```text
使用 $bioinformatics-plotting，根据已有差异分析结果和方法说明绘制火山图，
保留比较方向与统计阈值，输出图片、绘图脚本、源数据和图注。
```

两部分衔接时，分析部分负责数据与统计正确性，绘图部分负责表达与图形质量。交接应包含稳定 ID、数值含义、单位、变换状态、比较方向、统计方法及结果来源。仅改变配色或排版不重跑分析；改变统计模型或分析样本则重新生成受影响结果。

## 当前状态

两部分都强调独立重跑和可核查交付：分析脚本记录生效配置、运行状态及输入输出验证；绘图记录显示筛选、组色映射及实际导出文件的视觉检查。分析计算与显示处理的界线明确，例如 PCA 拟合属于分析，坐标绘制属于绘图。

当前提供两个 skill 的工作规范与界面元数据，已通过结构校验。它们指导代理按具体数据任务编写或复用脚本；仓库尚未附带完整的可执行生信流程库、绘图模板库或真实数据端到端验证结果。

使用时需要在支持该格式的工具中加载相应 skill，并提供输入文件与任务要求。所需分析软件、数据库及绘图环境由具体项目决定。
